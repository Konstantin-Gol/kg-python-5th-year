ILOVEYOU virus

The ILOVEYOU virus is one of the most destructive viruses in history

The virus spread through an email called ILOVEYOU and contained a attachment called LOVE-LETTER-FOR-YOU.txt.vbs

The file looked like a .txt file, but it was actually a .vbs script and people didn't suspect it because Microsoft Windows hid file extensions by default, users didn’t see the real file type

Once opened, it used Microsoft Outlook to send itself to all contacts in the victim’s address book and within 24 hours millions of computers were infected

Governments, companies, and banks worldwide had to shut down email systems and it caused an estimated global damageof around $5–10 billion.

Around 45–50 million computers were affected

the virus destroyed every file the computer had when installed
